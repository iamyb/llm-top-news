# llm-top-news

Trending news aggregator for the LLM ecosystem: GitHub rising-star repos × high-scoring HN posts × Reddit hot posts, deduplicated across sources and ranked by heat.

## Layout

```
config.yaml             # keywords / thresholds / subreddits for all sources (core config)
pipeline/
  collect.py            # collection: GitHub Search + HN Top Stories/MiniLM + Reddit top → data/raw/YYYY-MM-DD.json
  semantic_filter.py    # local MiniLM semantic ranking
  digest.py             # aggregation: cross-source dedup + 🔥 markers + LLM summaries → log/daily/ or log/weekly/
  site.py               # static site generator → site/ (GitHub Pages)
data/                   # raw snapshots & state
log/
  daily/YYYY-MM-DD.md   # daily digest
  weekly/YYYY-Www.md    # weekly digest
site/                   # generated static site (deployed to gh-pages)
```

## Quick start

```bash
pip install -r requirements.txt

# Optional: put env vars in .env at the repo root (gitignored, auto-loaded by scripts)
# GITHUB_TOKEN=xxx          # recommended, raises GitHub Search API rate limits
# LLM_API_BASE/KEY/MODEL    # optional, any OpenAI-compatible endpoint; falls back to truncated text if unset

python pipeline/collect.py              # collect today's snapshot
python pipeline/digest.py --mode daily  # generate daily digest
python pipeline/digest.py --mode weekly # generate weekly digest (merges the last 7 days)
python pipeline/site.py                 # rebuild the static site
```

HN pulls the first 100 Top Stories, filters by time/score, then runs a `hn.pre_filter_keywords` pre-filter (130+ LLM-related keywords, lowercase substring match) followed by a local `all-MiniLM-L6-v2` semantic ranking. An item is selected only if it passes the pre-filter **and** scores ≥ `min_score`; the top 10 are kept by default. The full candidate list (with scores/ranks/pre-filter flags) is saved to `data/raw/YYYY-MM-DD.hn_candidates.json` for manual recall review. Config lives under `hn.semantic_filter` in `config.yaml`; set `enabled: false` to disable. GitHub Actions caches the Hugging Face model directory, so only the first run downloads the model.

## Data sources

| Source | Method | Notes |
|---|---|---|
| GitHub | Search API: 10 topics, querying newly created and recently active repos separately (~20 requests), sorted by stars | "New" and "active" boards are shown separately |
| HN | Firebase Top Stories top 100 → time/score filter → keyword pre-filter → local MiniLM semantic ranking | candidates ≥30 points; selection requires passing the pre-filter and ≥0.20 semantic score; top 10 by default |
| Reddit | `r/<sub>/top/.rss?t=day` via proxy, no OAuth needed | 5 subreddits by default (LocalLLaMA, LLMDevs, LocalLLM, Singularity, StableDiffusion); edit the list in `config.yaml`; a proxy is required where reddit.com is blocked |
| HF Papers | `huggingface.co/api/daily_papers`, sorted by upvotes | daily AI paper picks, top 15 by default (`hf_papers.limit`) |

## Aggregation rules

- Titles are normalized (lowercase + punctuation stripped); similarity ≥0.75 or identical URL → same story
- A story appearing in ≥2 sources → 🔥 cross-source hotspot, pinned to the top
- No seen-state: top boards are snapshots; the day's raw file *is* the day's snapshot, and re-runs simply overwrite it

## Automation

A GitHub Actions workflow (`.github/workflows/daily.yml`) runs every 8 hours (UTC 0/8/16 = Beijing 08:00/16:00/00:00):

- **collect**: overwrites the current day's snapshot (no seen-state), so history keeps only the day's final version
- **digest**: the daily report is generated by the first run of the day (deduplicated via `data/processed_dates.json`); one daily report and one weekly report per period
- **site**: rebuilt and deployed to the `gh-pages` branch → public via GitHub Pages
- data/ and log/ are committed back to `main` so the archive accumulates history

`workflow_dispatch` supports manual triggers.

## Design discipline

- Outputs are drafts — review before publishing
- Snapshots, not tracking: re-running for the same day overwrites; there is no incremental "seen" state
